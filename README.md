# Play Time Database: Data

Shared data for the Play Time Database project in ARTG 3400, Topics in Interaction Design Inquiry: Playful Intervention, Fall 2026. Forty-one observations of play at Northeastern, collected by the class.

## What's here

- `data/play-time-database.csv` has all 41 entries, one row each.
- `photos/` has one photo per entry, named by row number, for example `photos/row-02.jpg`.

## Using it in your site

Every file here has a public web address:

- Data: `https://YOUR-USERNAME.github.io/play-time-database-data/data/play-time-database.csv`
- A photo: `https://YOUR-USERNAME.github.io/play-time-database-data/photos/row-02.jpg`

The `photo` and `video` columns in the CSV give each entry's file path. Add it to the address above to get the full link.

## About the data

- The `row` column matches the row number in the Google Sheet.
- Observer names and email addresses were removed.
- One date typo was fixed: row 15 said 2025 and is now 2026.
- Row 17 has no photo. Row 26 has a short video (`photos/row-26.mp4`) as well as a still.
- Everything else is exactly as the observers wrote it, including "Other" answers and typos. Deciding what to do with messy answers is part of your design work.
